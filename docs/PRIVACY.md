# Приватность

## Какие данные покидают компьютер

- Во время активного прослушивания PCM-аудио отправляется в OpenAI Realtime API для STT.
- Контекст текущего запуска, включая транскрипцию, текстовые вопросы и ответы, отправляется
  выбранному provider при подготовке следующего ответа или итогов.
- Для ответа из профиля отправляются только локально выбранные релевантные фрагменты профиля,
  вакансии и дополнительных материалов.
- Снимок экрана отправляется только в режимах `Умный`, `Всегда` или после ручного включения.
- Импортированные аудио и видео отправляются в OpenAI Audio Transcriptions API для получения
  текста. Текстовые документы, PDF и DOCX разбираются локально.

## Что хранится локально

- настройки RepGlass;
- Platform API key, зашифрованный Electron `safeStorage` (Windows DPAPI или macOS Keychain);
- профиль кандидата, вакансия и извлечённый текст материалов, зашифрованные тем же механизмом;
- OAuth-состояние Codex в официальном хранилище Codex;
- временный PNG экрана только на время одного запроса.

RepGlass хранит историю активной сессии только в памяти процесса. Она очищается командой
«Новая сессия» или при полном перезапуске. Приложение не записывает аудио и историю на диск и
не отправляет собственную аналитику. В нём нет Firebase, Portkey, Slack webhook или рекламного SDK.
Профиль интервью хранится между запусками отдельно от истории сессии и удаляется явной кнопкой
«Очистить» в разделе «Профиль».

## Удаление данных

- OpenAI API key удаляется кнопкой «Удалить» в настройках.
- Codex OAuth завершается кнопкой «Выйти».
- Профиль, вакансия и импортированные материалы удаляются кнопкой «Очистить» в профиле.
- Деинсталлятор по умолчанию сохраняет настройки; их можно удалить вручную из
  `%APPDATA%\RepGlass`.
- На macOS локальные данные находятся в `~/Library/Application Support/RepGlass`.
- Просроченные временные screenshots старше часа удаляются при следующем захвате.

Политика обработки данных самим OpenAI определяется условиями вашего ChatGPT/Platform
аккаунта и настройками организации.

На macOS защита окна Electron не гарантирует скрытие от приложений захвата,
использующих ScreenCaptureKit. При собственном снимке RepGlass временно скрывает
своё окно и значок в строке меню.
