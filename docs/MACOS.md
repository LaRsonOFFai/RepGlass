# RepGlass для MacBook

**Статус: экспериментальная версия, требует тестирования на реальном Mac.**
Сборка DMG, запуск и реальный аудиозахват на macOS пока не подтверждены.
Локальные проверки выполнены на Windows и не подтверждают работоспособность на Mac.

Подготовлена сборка для **macOS Sonoma 14.2 и новее**:

- **Apple Silicon (M-процессоры)** — `arm64`, нативное приложение без Rosetta.
- **Intel** — `x64`.

Готовый macOS-релиз ещё не опубликован. Сборка и проверка запуска выполняются
в GitHub Actions на отдельных macOS runners. Успешный запуск workflow создаёт
артефакты `RepGlass-macOS-arm64` и `RepGlass-macOS-x64` с DMG и ZIP.
Автоматическая проверка запуска не проверяет реальные разрешения и аудиозахват.

## Установка и разрешения

1. Выберите пакет под процессор MacBook. Откройте DMG и перенесите RepGlass в Applications.
2. Запустите приложение. Тестовая сборка имеет локальную ad-hoc подпись,
   но не сертификат Developer ID и не нотариализацию Apple. macOS может заблокировать запуск;
   для доверенной сборки используйте «Всё равно открыть» в Системных настройках →
   Конфиденциальность и безопасность.
3. Настройте подключение в RepGlass так же, как в Windows.
4. При первом прослушивании разрешите доступ к микрофону, а для системного звука —
   запись системного аудио и экрана. Для снимков экрана также нужно разрешение записи экрана.
   Эти разрешения находятся в Системных настройках → Конфиденциальность и безопасность.
   После изменения разрешений полностью завершите RepGlass и откройте снова.

Глобальные сочетания используют **⌘**: ⌘+Shift+G — показать/скрыть,
⌘+Shift+Q — Ask, ⌘+Shift+L — прослушивание, ⌘+Enter — умный запрос.
Приложение доступно через значок в строке меню.

Ключ API и материалы профиля шифруются Electron safeStorage с использованием macOS Keychain.
Защита окна от захвата имеет ограничение: приложения, использующие ScreenCaptureKit,
могут захватывать окно даже с включённой защитой. При собственном снимке RepGlass
временно скрывает окно и значок в строке меню.

## Сборка на Mac

Нужны Node.js 24+ и npm 11+. Из корня репозитория:

```sh
npm --prefix app ci
npm run verify
npm run build:mac:arm64  # MacBook с M-процессором
# npm run build:mac:x64 # MacBook с Intel, собирать и проверять на Intel Mac
npm run smoke:packaged
```

Результат: `app/release/RepGlass-<версия>-macOS-arm64.dmg` и ZIP
(для Intel в имени будет `x64`). `npm run build:mac` собирает для процессора текущего Mac.
Сборка DMG требует macOS; на Windows можно проверить TypeScript, тесты и сборку приложения.

Для публичной подписанной версии нужно заменить `build.mac.identity` на Developer ID,
включить `build.mac.notarize` и настроить сертификат и credentials Apple в среде сборки.
Сертификаты и пароли не хранятся в репозитории.

Перед публикацией проверьте на физическом Mac: вход в Codex, микрофон, системный звук,
оба источника одновременно, снимки экрана, отказ в разрешениях, перезапуск после выдачи
разрешений, горячие клавиши и показ окна поверх полноэкранного приложения.

Справка: [аудиозахват Electron](https://www.electronjs.org/docs/latest/api/desktop-capturer),
[защита окна](https://www.electronjs.org/docs/latest/api/browser-window#winsetcontentprotectionenable),
[сборка macOS в electron-builder 26](https://www.electron.build/v26/docs/mac/).
