# RepGlass

AI-помощник для Windows: переводит разговор в текст, подсказывает ответы на вопросы
и помогает разбирать задачи на экране. Всё — в одном компактном полупрозрачном окне.

**macOS: экспериментальная версия, требует тестирования.** Подготовлена
[версия для MacBook с M-процессорами и Intel](docs/MACOS.md) (macOS 14.2+).
Сборка, запуск и аудиозахват на Mac пока не проверены; готовый macOS-релиз не опубликован.

## Скачать

**Для Windows 10/11, 64 бит. Готовая версия — 1.2.0.**

- **[Скачать установщик](https://github.com/LaRsonOFFai/RepGlass/releases/download/v1.2.0/RepGlass-Setup-1.2.0-x64.exe)** — установите и запустите RepGlass через ярлык.
- [Скачать версию без установки](https://github.com/LaRsonOFFai/RepGlass/releases/download/v1.2.0/RepGlass-Portable-1.2.0-x64.exe) — запустите скачанный файл.

[Все релизы](https://github.com/LaRsonOFFai/RepGlass/releases). Для готовой версии Node.js и сборка из исходников не нужны.

Windows может показать предупреждение SmartScreen: версия 1.2.0 пока не имеет цифровой подписи.

## Первый запуск

1. Откройте **Настройки → Подключение** и нажмите **«Войти»** в блоке OpenAI Codex.
2. Для распознавания речи добавьте [ключ OpenAI API](https://platform.openai.com/api-keys) и сохраните его.
3. В разделе **«Аудио»** выберите **«Оба источника»**, затем нажмите **«Слушать»**.

Для ответов нужен аккаунт с доступом к Codex. Распознавание речи оплачивается отдельно
через OpenAI API; подписка ChatGPT его не покрывает.

Вопрос можно также написать в **Ask**. **Пауза** сохраняет разговор,
**«Завершить»** формирует итоги. Показать или скрыть окно — **Ctrl+Shift+G**.
